# AI Personal Study Planner

A Python-based study planner that creates personalized study schedules and tracks student progress.

## Features

- Personalized study plan
- Subject and topic selection
- Study hour management
- Difficulty-based planning
- Progress tracking
- AI Study Assistant
- PDF study notes support
- Study plan download

## Technologies Used

- Python
- Streamlit
- Pandas
- Google Gemini AI
- PyPDF

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required packages.
4. Run the Streamlit application.

```bash
streamlit run app.py
